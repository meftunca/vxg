Key architectural mechanisms validated via isolated Apple M2 Max micro-benchmarks prior to integration:

1. **Hybrid arena weight layout (`NR=2` step-major layers + `NR=4` tile-major vocab)** in single 256-byte-aligned `weight_arena_buf`:
   - On `2,048..12,288`-row layer projections, `NR=4` tile-major suffered `4,096`-byte (`2^12`) tile-stride cache-set/DRAM bank aliasing and wave starvation (`59 GB/s` on `2048x2048` `w_out`). Repacking layer matrices into **`NR=2` step-major (`ushort2` scales / `uint2` words indexed by `(step, tile, lane)`)** makes all 32 SIMD lanes read contiguous cachelines and doubles active SIMD waves (`262.2 GB/s` on `w_in`, `272.7 GB/s` on `ffn_gu`, `221.2 GB/s` on `ffn_dn`, `97.0 GB/s` on `w_out`).
   - On `248,320`-row `token_embd` and `output.weight` (`lm_head`), step-major spans `31.8 MB` per step and triggers TLB thrashing (`139 GB/s`); retaining **`NR=4` tile-major** keeps every `4 KB` 4-row tile inside a single `16 KB` VM page (**`325.5 GB/s`**).
2. **32-bit SRAM `c16` codebook LUT (`0-ULP` cubic equivalence)**:
   - Each threadgroup pre-evaluates the 16 `eval_cubic4` values into `threadgroup float c16[16]` (`64` bytes per sub-matrix) in exact IEEE-754 FMA order (`mathMode = MTLMathModeSafe`), eliminating 96 scalar polynomial FMAs per 256-column step while matching `MetalLlmRunner` to `0 ULP`.
3. **Eliminating cross-core RMW cacheline contention (`vxt_cb4_add_rms_norm_batch`)**:
   - Writing residual projections (`w_out`, `w_ffn_dn`) into write-only `delta_buf` and fusing `cur += delta` into the subsequent `RMSNorm` eliminated 512-TG read-modify-write cacheline ping-pong across M2 Max's 30 GPU cores (saving `-1,298 us/tok` on the 24-layer FFN alone while preserving IEEE-754 addition commutativity).
4. **4-row/SG zero-spill `vxt_cb4_ffn_gu_nr2_m1`**:
   - Fuses `[ffn_gate; ffn_up] + SwiGLU` by pairing 2 Gate rows + 2 Up rows per SIMD group (`4` accumulators total — identical register footprint to `NR=4` GEMV), saving `-770 us/tok` and eliminating `ffn_gu_buf` DRAM traffic during `M=1` decode.
5. **64-TG split-state FP32 DeltaNet + single-dispatch `M=1` GQA + batched `NR=2 x BM=8` prefill**:
   - Splits each of the 16 recurrent value heads into 4 row-slices (`64` TGs across 30 GPU cores) in `vxt_cb4_dnet_state_split_m1` + `vxt_cb4_dnet_out_m1`, fuses Conv1D + `[ssm_alpha; ssm_beta]` GEMV into single-wave `vxt_cb4_dnet_prep_m1`, fuses `M=1` GQA QKV norm/RoPE + Flash-Decoding into `vxt_cb4_gqa_fused_m1`, and replaces serial per-token prefill loops with `vxt_cb4_gemm_nr2` (`BM=8`) + batched DeltaNet/GQA kernels.
6. **Parallel loader + 20-PSO `dispatch_apply` + IOMMU page-wiring warmup + 2-deep 8-step pipelined `MTLCommandBuffer` ring**:
   - Parallelizes `read_vxt_model` decompression, arena packing, and Metal PSO compilation across CPU cores, wires GPU page tables during `load_file` via a 64-byte blit warmup, and overlaps 2x8-token greedy decode bursts with exact FP32 state checkpoint/replay on stop tokens, callback abort, or panics.

## Rejected candidates (measured and excluded)

- `constant float2* lut256` 2-nibble LUT (`116 tok/s`): Apple GPU uniform constant-cache divergence replay across 32 lanes.
- `cb4_decode_alu` in-register polynomial (`136 tok/s` vs `173 tok/s` SRAM `c16`): scalar ALU bottleneck.
- `simd_shuffle` 16-entry register LUT (`75 GB/s`): SIMD crossbar serialization.
- `threadgroup float x_sh[6144]` input staging (`83–119 GB/s` on `ffn_dn`): `24 KB` TG memory cut occupancy to 1–2 TGs/core, defeating M2 Max's hardware L1/L2 broadcast cache.
- `VXT_COHERENT_DEV` single-dispatch `gemv_nr4_epi` (`+469 us/tok` slower): ~12,000 device-scope `seq_cst` atomic fences per token stalled L2 writeback pipelines.
- 8-row/SG `ffn_gu_swiglu_m1` (`+236 us/tok` slower) and 16-TG monolithic `dnet_fused_m1` (`+396 us/tok` slower): register pressure and 16-TG GPU core under-utilization (`16 < 30` cores).
