## Withdrawn candidate

[Shader](/private/tmp/vxg-real-qualification-20261104/cb4-poly-lut-20261104/source/crates/vxg-tensor/native/shaders/vxt_gemv.metal): the shared per-row function has a compile-time boolean. Existing rows2 and rows4 instantiate false, retaining their polynomial evaluation expressions. The sole new variant instantiates true with rows2. Before the weight loop each SIMD lane evaluates the existing strict `eval_cubic4(float4(float(lane & 15)-7.5), ...).x`; lanes 0–15 and 16–31 hold duplicate copies of the 16 existing polynomial outputs. Eight `simd_shuffle` lookups reconstruct each packed word's weights. Dot/FMA/scale/sparse outlier/reduction order remains shared and unchanged. This does not use the CPU learned-centroid table and does not move the scale multiplication.

[Context selection](/private/tmp/vxg-real-qualification-20261104/cb4-poly-lut-20261104/source/crates/vxg-tensor/native/metal_gemv.mm) captures `VXG_CB4_POLY_LUT=1` once per opaque GPU context, selecting a PSO from the existing strict-math library (`fastMathEnabled=NO`). Combining this with `VXG_CB4_ROWS4=1` explicitly rejects context creation. Existing rows4 code is retained. Archived-candidate reproduction only (the flag is absent from final live source):

