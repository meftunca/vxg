<h1 align="center">VXT Studio</h1>
<p align="center">
  <strong>Desktop UI for <code>VXT-Turbo</code> Compressed-Domain Local LLM &amp; Vision Inference</strong>
</p>

`apps/vxt-studio` is the companion desktop studio for [`crates/vxg-tensor`](../../crates/vxg-tensor) (`.vxt` models), offering model management, interactive chat & vision prompting, live token/s telemetry, and OpenAI-compatible local endpoint controls.

See **[`crates/vxg-tensor/README.md`](../../crates/vxg-tensor/README.md)** and **[`docs/TENSOR.md`](../../docs/TENSOR.md)** for engine build options (Apple Metal / NVIDIA CUDA).
